# SRAM

## 主题概述

静态随机存取存储器（Static Random-Access Memory，SRAM）是一类使用双稳态锁存结构保存数据的易失性存储器。只要电源持续供电，SRAM 就不需要像 DRAM 一样周期性刷新，具有低延迟、高带宽和易于片上集成等特点，广泛用于处理器 Cache、寄存器文件、片上缓冲区和各类 SoC 存储子系统。

## 基本原理

经典 6T SRAM 位单元由两个交叉耦合反相器和两个访问晶体管组成。交叉耦合反相器形成双稳态结构，分别表示逻辑 0 和逻辑 1；字线（WL）控制访问晶体管，互补位线（BL/BLB）承担读写数据传输。

- 保持：WL 关闭，位单元与位线隔离，锁存器维持内部状态。
- 读操作：位线预充电后开启 WL，存储节点通过访问晶体管使一侧位线产生微小压差，再由灵敏放大器判决数据。
- 写操作：写驱动器在 BL/BLB 上施加强制电平并开启 WL，使锁存器翻转到目标状态。

## 常见位单元

- 6T：面积小、密度高，是通用 SRAM 的主流结构，但读稳定性与写入能力相互制约。
- 8T：增加独立读端口，将读路径与存储节点隔离，可改善读稳定性，代价是面积和布线开销增加。
- 10T 及更多晶体管结构：常用于低电压、高可靠性或多端口场景，通过读写解耦、差分读出或反馈控制改善稳定性。
- 多端口单元：支持同时读写或多路访问，常见于寄存器文件，但面积和功耗显著增加。

## 关键设计指标

- 面积与密度：通常以位单元面积和阵列利用率衡量。
- 访问时间：包括地址译码、字线驱动、位线发展、灵敏放大和输出路径延迟。
- 动态功耗：主要来自位线充放电、字线切换和外围电路活动。
- 漏电功耗：在大容量阵列和先进工艺中占比突出，与器件阈值、电源门控和数据状态有关。
- 静态噪声容限（SNM）：衡量保持与读取状态下抵抗噪声扰动的能力。
- 写入裕量：衡量写驱动器克服位单元反馈并完成翻转的能力。
- 最低工作电压（Vmin）：由器件失配、读写裕量、外围电路和目标良率共同决定。
- 良率与可靠性：需要考虑工艺波动、软错误、老化、电迁移和电源噪声等因素。

## 阵列与外围电路

SRAM 宏通常由位单元阵列、行列译码器、字线驱动器、预充电电路、写驱动器、灵敏放大器、列复用器、时序控制和冗余修复结构组成。实际 PPA 不仅取决于位单元，还受到阵列长宽比、行列复用、Bank 划分、位线与字线 RC、外围布局以及电源网络的显著影响。

## 设计与验证流程

1. 根据容量、字宽、端口数、频率、电压和工艺确定宏规格。
2. 选择位单元及阵列组织，完成读写稳定性和器件尺寸权衡。
3. 设计译码、驱动、感放、预充电和控制等外围电路。
4. 在 PVT Corner 与 Monte Carlo 条件下验证功能、时序、功耗、裕量和失效率。
5. 完成版图、DRC/LVS、寄生参数提取及后仿真。
6. 通过冗余、ECC、BIST 和 Repair 提升测试覆盖率与产品良率。
7. 将结果抽象为时序、功耗和物理视图，供数字实现流程或 Memory Compiler 使用。

## 核心设计权衡

- 读稳定性与写入能力：增强访问管有利于写入，却可能在读取时加剧存储节点扰动。
- 性能与功耗：更大的驱动能力和更快的位线发展通常增加动态功耗与面积。
- 密度与低压可靠性：高密度 6T 单元在低电压下更容易受到失配和噪声影响。
- 局部优化与宏级收益：位单元面积缩小并不必然带来等比例宏面积改善，外围电路与布线可能成为瓶颈。

## 先进工艺研究方向

- 低电压 SRAM：通过辅助写入、读写解耦、动态电源调节等技术降低 Vmin。
- FinFET、GAA、CFET 与 FFET SRAM：研究新器件结构对位单元面积、失配、寄生和双面互连的影响。
- 3D SRAM：利用单片三维集成或晶圆级堆叠提升密度与带宽，同时处理热、层间互连和测试问题。
- Near-Memory 与 In-Memory Computing：减少数据搬运，或直接利用 SRAM 阵列执行逻辑与乘加运算。
- 自动化设计：通过 Memory Compiler、统计仿真和设计空间搜索联合优化单元、阵列与外围电路。
