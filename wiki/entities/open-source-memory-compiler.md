# [[Open Source Memory Compiler]]

## 1. 基本信息（Basic Info）

- 类型：工具
- 简要描述：用于生成或探索 memory 宏版图与参数空间的开源编译器工具链。

## 2. 背景介绍（Background）

- 历史：开源 memory compiler 逐渐成为学术界研究 SRAM 与 memory macro 自动化设计的重要基础设施。
- 发展：在 3D SRAM 研究中，这类工具被用于探索三维集成条件下的 PPA 与结构组合。

## 3. 核心能力 / 产品（Key Features）

- 自动化生成 memory 宏设计候选
- 支持对面积、时序和结构参数做设计空间探索

## 4. 关键作用（Role）

在相关领域中的作用：为 3D SRAM 的结构优化与快速比较提供可复用的设计工具基础。
