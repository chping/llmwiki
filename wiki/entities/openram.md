## 简介

`OpenRAM` 是面向 SRAM 宏生成的开源 memory compiler。本次导入的
3D SRAM 论文以该工具为基础，扩展了多层 SRAM 的自动版图生成以及
配套功耗、时序分析能力。[3D SRAM Design & Optimization with Open
Source Memory
Compiler](../../raw/2026/04_26/3D_SRAM_Design_amp_Optimization_with_Open_Source_Memory_Compiler.pdf)

## 本次资料中的角色

- 作为 2D memory compiler 的基础平台，被扩展用于 3D SRAM 自动化设计。
- 使 3D SRAM 研究能够围绕容量、层数和工艺库输入快速生成候选实现。
- 为后续评估面积、功耗与读延迟提供统一实验入口。
